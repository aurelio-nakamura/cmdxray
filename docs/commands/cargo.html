cargo subcommands

cargo flags & options

--all-featuresactivate all Cargo features
--no-default-featuresdo not activate the default feature set
--featuresspace/comma-separated list of features to activate
--workspacerun the command for every package in the workspace
--packagerun the command for this package only
--binbuild/run only this binary target
--examplebuild/run this example target
--targetbuild for the given target triple
--lockedrequire an up-to-date Cargo.lock and don't change it
--offlinerun without accessing the network
