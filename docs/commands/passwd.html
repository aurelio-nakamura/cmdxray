passwd flags & options

-llock the account's password (prefix it with !)
-uunlock a locked password
-ddelete the password, leaving the account passwordless
-eexpire the password now, forcing a change at next login
-Sshow password status (locked/usable, last change)
-awith -S, report status for all accounts
-nminimum days between password changes
-xmaximum days a password stays valid
-wdays of warning before a password expires
-idays after expiry until the account is disabled
