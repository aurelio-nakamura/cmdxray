umount flags & options

-aunmount every filesystem listed in /etc/mtab
-fforce the unmount (useful for an unreachable NFS mount)
-llazy unmount — detach now, clean up once it is no longer busy
-rif the unmount fails, remount the filesystem read-only instead
-nunmount without writing to /etc/mtab
-Rrecursively unmount the given directory and everything below it
-tact only on filesystems of the given type
-vverbose output
-Oact only on filesystems with the given mount options
